# Frontend Projects

This repository is a collection of beginner-to-intermediate frontend practice projects built with HTML, CSS, JavaScript, and one small Python-based CRUD example. The goal is to strengthen UI design, layout skills, component styling, and simple web app logic through hands-on builds.

## Overview

The projects here range from static landing pages and UI clones to small interactive front-end experiments and a basic database-driven Python app. Most folders are standalone mini-projects, so each one can be opened and run independently.

## Project categories

### UI clones and landing pages

- Amazon-Clone — e-commerce homepage clone
- CopyPortfolio — portfolio page mockup
- Gardeners — gardening brand landing page
- HeathCare — healthcare-themed website
- Viso3D — modern 3D-inspired landing page
- Order-Details-UI — order summary / ecommerce detail layout

### CSS and UI experiments

- BackgroundGlow — glowing background effect
- CSS_Mini_Project — CSS buttons, styling experiments, and mini components
- NavBAr — responsive navigation bar practice
- Ninja-Login_page — login page design
- Parllax — parallax scrolling effect demo

### Music and media UI builds

- Spotify_Clone — stronger Spotify-inspired UI implementation retained as the final version

### Python app

- python-SQL-basic-CRUD — basic student record management app using Python + SQL

## How to run the projects

### Static HTML/CSS/JS projects

Open any project's `index.html` file in a browser, or use a live preview / VS Code live server extension.

Example:

```bash
# from the repo root
cd Amazon-Clone
# open index.html in browser
```

### Python CRUD project

```bash
cd python-SQL-basic-CRUD
python main.py
```

## Notes

- Most projects are self-contained and do not require a framework.
- The duplicate Spotify implementation was removed after comparing both versions; the stronger one is retained as [Spotify_Clone](Spotify_Clone).
- This repo is best treated as a practice portfolio and learning archive rather than a single production app.
